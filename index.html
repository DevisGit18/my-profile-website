Hierarchical Safe DRL with Event-Triggered CBF for UAV Dynamic Obstacle Navigation

Final Year Project · 2026–Ongoing

Supervised by Dr. P. Arun Mozhi Devan, Amrita Vishwa Vidyapeetham

Designing a hierarchical framework for single-UAV autonomous navigation combining Soft Actor-Critic (SAC) for path planning, Control Barrier Function with quadratic programming (CBF-QP) for formal collision safety guarantees, and an event-triggered replanning mechanism for computational efficiency. Implemented a custom ObstacleAviary simulation environment in PyBullet (gym-pybullet-drones) with static and velocity-driven dynamic spherical obstacles; progress-based reward shaping with collision penalty and smoothness terms. Conducting a 100-episode ablation study across four model variants (pure SAC, SAC+CBF, SAC+Event-Trigger, full hierarchical system), evaluating success rate, collision rate, path length, and computation time. Target: MDPI Drones.

Status: ongoing, ablation study in progress.
